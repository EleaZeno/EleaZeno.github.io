## 一句话

聊天机器人给你答案；agent 替你动手——搜索、写文件、点按钮、跑命令，并根据结果决定下一步。

## 关键区别在"循环"

普通问答是一次性的：输入 → 输出 → 结束。

agent 是个循环：**观察现状 → 决定动作 → 执行 → 看结果 → 再决定**，直到任务完成或放弃。这个循环让它能处理多步骤任务，也让它的失败方式更复杂——中间任何一步判断错，后面会连锁跑偏。

## "框架"和"模型"不是一回事

这是读 agent 相关新闻时最需要分清的一点：

- **模型本身**变强：同样的提问，答得更好
- **框架**变强：模型没变，但外围工程变好了——更好的任务拆解、失败重试、允许写脚本代替手工点击、给更多尝试步数

两者都能让榜单分数上升，但含义完全不同。一个框架把现有模型的成绩提高二十个百分点，这是了不起的工程，却不代表模型的能力边界移动了。
