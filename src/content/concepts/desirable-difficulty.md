## 一个让人不服的实验结果

八岁的孩子练习闭着眼把沙包扔到地上的目标上。一组**只**在 3 英尺处练，另一组在**更近和更远**的位置练——从来不在 3 英尺练。

然后所有孩子都在 3 英尺处测试。

谁会赢？常识说是第一组：他们练的就是考的。

实际结果是第二组赢，两个年龄组都是（Kerr & Booth, 1978）。从没在 3 英尺练过的孩子，在 3 英尺上扔得更准。

## 朴素解释，以及它为什么不够

第一反应是"巧合"或"样本问题"。但这类结果太多了，且方向一致：变换学习地点比固定地点记得多，打乱题型比集中刷题效果好，自测比重读留得久。

第二反应是"练得杂所以适应性强"。这个方向对，但它没解释**为什么代价是当下表现变差**——变化组在练习过程中的成绩通常更难看。

需要一个能同时解释"当下更差"和"长期更好"的机制。这个机制就是[存储强度与提取强度](/concepts/storage-retrieval-strength/)的分离：固定练习让提取强度飞快上升（同一个动作反复调用，越调越顺），但正因为条件恒定，它没有迫使大脑去建立可迁移的连结。变化练习牺牲当下的顺畅，换来更密的连结——也就是更高的存储强度。

## 机制：难度做了什么

必要难度之所以有效，不是因为"吃苦有德"，而是因为特定类型的困难**强迫大脑做额外的编码与提取工作**。

对比一下两种复习方式：

```
重读一遍：          眼睛扫过文字 → 认出来 → "这个我知道"
                    大脑做的工作：识别（很便宜）

合上书回想：        搜索 → 部分失败 → 重构 → 检查
                    大脑做的工作：提取 + 重建（很贵，但留下痕迹）
```

第二种更费劲，主观上也更不愉快——你会卡住，会想不起来。而正是这个卡住的过程在改写记忆。

四种最有证据的必要难度：

1. **变化练习**：换地点、换条件、换参数（沙包实验）
2. **间隔**：把复习摊开，而不是挤在一起
3. **[交错](/concepts/interleaving/)**：打乱不同类型的内容，而不是分块攻克
4. **[提取练习](/concepts/retrieval-practice/)**：用自测代替重读

## 回访：这个词里最重要的是 desirable

这是全部内容里最容易被丢掉、丢掉就会把整个概念用坏的一段。

原作者专门强调：**很多困难在学习中是有害的，而且此后一直有害**。必要难度之所以"必要"，是因为它触发了支持学习、理解和记忆的编码与提取过程。但——

> 如果学习者不具备成功应对它们所需的背景知识或技能，它们就变成了有害的困难。

所以判据**不是难度的大小，而是难度是否落在"能被成功应对"的范围内**。同一份材料，对准备好的人是必要难度，对没准备好的人是纯粹的障碍。

这也是为什么"把英文原始论文直接扔给初学者"不是必要难度：如果连术语都不认识，它触发不了编码与提取，只触发放弃。要把它变成必要难度，得先把前置知识垫到"能读懂大部分、卡在少数几处"的水平。

## 边界与常见误解

**不等于"越难越好**"。这是最常见的误用。难度需要被成功应对，否则无效甚至有害。

**不等于"不要讲清楚**"。教学要做的是**把困难放在对的位置**（让学生自己生成答案），不是把解释写得含混。含混是 undesirable difficulty。

**主观感受不是指标**。必要难度的标志恰恰是当下感觉更差。所以不能用"学得爽不爽"来判断是否用对了，只能靠延迟测试。参见[元认知错觉](/concepts/metacognitive-illusion/)。
